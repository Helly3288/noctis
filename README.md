# Ноктис: год Лео Вельта

Нарративная РПГ в духе *The Life and Suffering of Sir Brante* в киберпанк-сеттинге.
Лео девятнадцать, он учится на инженера, чинит импланты в мастерской отца и не знает, что создан в лаборатории корпорации «Церебра».

**Играть:** https://helly3288.github.io/noctis/

## Что внутри
- `index.html` — игра целиком: движок, сюжет, музыка, заставки. Один файл, без установки.
- `docs/bible.md` — библия проекта: мир, персонажи, правила механик.
- `docs/scenes.md` — каркас сцен на весь год.
- `docs/prompts.md` — промпты для иллюстраций (Kandinsky), 76 картинок.
- `img/` — готовые картинки; `tools/images.py` подключает новые.

## Статус
Полная версия года: сентябрь–апрель, 32 сцены, 5 финалов, около трёх часов.

Что есть в игре:
- проверки с шансом, видимым заранее, и бонусами за прошлые выборы;
- рост характеристик от поступков и итог каждого месяца с «Новостями Ноктиса»;
- два свободных вечера в месяц: с кем провёл, та линия и развивается;
- скрытая Странность, которая открывается после правды о Лео;
- экран «Что стало с…» в финале.

Дальше: прохождение второй половины года автором, отзывы тестеров, решение по кредитам, иллюстрации.
