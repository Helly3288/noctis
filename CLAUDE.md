# Ноктис: год Лео Вельта

Нарративная РПГ в духе The Life and Suffering of Sir Brante, киберпанк. Автор идеи — владелец репозитория, он не программист: общаемся по-русски, коротко, решения по сюжету задаём вопросами с вариантами.

## Файлы
- `src/game.html` — источник игры (движок + сюжет + музыка + заставки). Правим только его.
- `index.html` — собирается из `src/game.html` командой `python3 tools/build.py`. Руками не править.
- `docs/bible.md` — библия: мир, персонажи, правила механик. Перед новыми сценами читать и соблюдать.
- `docs/scenes.md` — каркас сцен на год. `docs/prompts.md` — промпты для иллюстраций.

## Картинки
- Генератор — Kandinsky, промпты и id всех 76 картинок в `docs/prompts.md`.
- Готовые промпты с кнопкой «Скопировать»: `prompts.html` (на Pages /noctis/prompts.html) и `docs/prompts_ready.md`. После правки `docs/prompts.md` пересобрать: `python3 tools/prompts_page.py`.
- Присланные файлы: `python3 tools/images.py <папка>` — сжимает в `img/<id>.webp` и обновляет список `IMAGES` в `src/game.html`. Потом обычная публикация.
- Заставка сцены = id сцены (`s1`, `rd_train`, `mon9`, `end_run`, `title`); арт внутри сцены — `{img:'char_teo', cap:'Тео Бартал'}` в тексте узла. Нет файла — заставка кодом, арт внутри сцены не показывается.

## Публикация
Правка `src/game.html` → `python3 tools/build.py` → коммит → push в `main`. Игра живёт только на GitHub Pages: https://helly3288.github.io/noctis/ (артефакт на claude.ai удалён по просьбе автора, новый не создавать).

## Правила, которые легко нарушить
- Странность: явных моментов не больше одного в месяц; скрытая Странность — побочный эффект разумных выборов, шкала скрыта до раскрытия правды (`SHOW_STRANGE = false`).
- В каждой острой сцене есть путь, проходимый со старта. Сложность: база, база+1, база+2 от стартовых статов Лео (Тело/Ловк/Воля 4, Обаяние 3, Техника/Рассудок 6).
- Каждая сцена начинается с отсылки к прошлым выборам и имеет время/причину.
- Диалог не обрывается на реплике NPC со скачком в другую сцену: последний узел сцены даёт игроку закрывающий выбор (попрощаться, спросить, уйти), а следующая сцена открывается мостом (сколько прошло времени, что было между). Голых «Продолжить» нет.
- До выбора обычно не больше 150 слов: длинную сцену делить на шаги с выбором-жестом. Прошлые выборы, которые помогают в проверке, оформлять бонусом `bonus:[…]`, а не молча.
- Кредиты пока нигде не тратятся — не добавлять траты без согласия автора.
- Перед публикацией прогонять случайные прохождения (Playwright) без ошибок.
